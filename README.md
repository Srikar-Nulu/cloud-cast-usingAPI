# Weather Forecast Web App

A simple and responsive weather application built using React, TypeScript, and the OpenWeatherMap API.  
Users can search for any city and view real-time weather details like temperature, humidity, wind speed, and weather description.

## Features
- Search weather by city name
- Shows temperature, humidity, wind speed
- Shows weather icon and description
- Clean and modern UI
- Fully responsive layout
- Error handling for invalid city or missing API key

## Technologies Used
- React
- TypeScript
- Tailwind CSS
- OpenWeatherMap API

## Project Structure

src/
├─ components/      → UI & reusable components  
├─ hooks/           → Custom hooks (toast, alerts, etc.)  
├─ pages/           → Page-level components  
├─ App.tsx          → Application entry  
├─ main.tsx         → React root  
└─ styles/          → Tailwind and global styles
